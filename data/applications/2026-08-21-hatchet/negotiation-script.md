# Negotiation Script: Hatchet (YC W24), Founding Engineer

Context going in: the listing discloses a base salary range of $160,000 to $199,999 for the role, based NYC or Remote (US and EU). No equity range is published, which is normal for a founding-engineer hire this early but means the number has to be asked for directly rather than assumed. The team is currently two second-time YC founders plus two founding engineers, so this hire is early enough that equity should be a real conversation, not a token grant. EU remote being explicitly on the listing removes the visa question that usually complicates these scripts, so this one can go straight to comp.

## Market context

- $160k-$199,999 is Hatchet's own disclosed band for the role, so it's the anchor whether the hire lands in NYC or EU remote. The open question is whether EU remote gets the same band or a haircut, ask early rather than assume parity.
- Geneva-based comp for a comparable Staff or founding-level engineering role runs roughly CHF 170,000-220,000 base. That's a useful sanity check against the disclosed USD band once currency and cost-of-living framing come up, but the disclosed band should stay the primary anchor since it's the company's own number, not a market estimate.
- Founding engineer equity at a seven-person, YC W24 company with two prior founding engineers already on board typically lands somewhere in the 0.25%-1% range with a standard 4-year vest, though this varies a lot with how the last round priced. Treat any number below that range as a starting offer to counter, not a final one.

## Opening position

"Thanks for sharing the range. Given the EU remote option is explicit in the listing, I'd want to confirm that applies at the same band as NYC before we get further, since I'm in Geneva. Assuming it does, I'd want to be talking near the top of the disclosed range, around $190,000, given the founding and platform experience I'd bring, plus a clear equity number so I can evaluate the full package rather than just the base."

## If they come in low, or try to apply a remote discount

"I'd want to understand the reasoning if the EU remote band is lower than the NYC one, since the listing doesn't distinguish between them. If there's a cost-of-living adjustment being applied, I'd rather hear the logic directly than guess at it. Geneva isn't a low cost-of-living market, so if the adjustment is modeled on a general remote discount rather than my actual location, that's worth revisiting."

Key move: don't let a remote discount get applied silently just because the number wasn't specified upfront.

## Equity and vesting questions to ask before agreeing to anything

- What percentage is on the table for this specific hire, not a general range.
- Last priced round and, if available, the most recent 409A valuation.
- Standard 4-year vest with a 1-year cliff, or something adjusted for how early this hire is relative to the first two founding engineers.
- Whether there's a refresh policy, or whether the initial grant is meant to cover the full early period.
- Double-trigger acceleration on an acquisition, worth asking given I've been on the acquired side of exactly that scenario once already at Alaya.
- ISOs versus RSUs, strike price, and the exercise window after departure.

## Framing the founding-engineer stage directly

"I want to make sure the equity reflects that this is effectively a third or fourth founding-engineer seat rather than a later hire into an established team. If the base is anchored to the disclosed band, I'd expect the equity to be anchored to how early this actually is, not a standard-issue grant."

## Competing offer template (use only if real)

"I'm further along in a process for a comparable role elsewhere, and the total comp there is tracking toward [$X] with [Y]% equity. I'd rather make this work if the numbers can get close, since the problem you're solving is the one I want to work on, but they'd need to be in the same range."

Only use this if there's an actual competing process in flight.

## Closing line for any round

"I want this to work for both of us. Send me something in writing on base and equity together, and I'll turn it around fast."
